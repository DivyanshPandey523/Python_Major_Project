#  Image Craft

Image Craft is a Python project I built to make basic image editing easier. It allows users to resize images, convert them into different formats, and apply a grayscale effect.

##  What It Can Do
- Resize images according to your needs
- Convert images into formats like PNG, JPG, and WEBP
- Turn coloured images into black and white
- Save edited images with the desired filename

##  Technologies Used
- Python
- Pillow
- Jupyter Notebook

##  Getting Started

Install Pillow before running the project:

```bash
pip install Pillow
```

##  How to Use
1. Open the notebook in Jupyter Notebook.
2. Run the code.
3. Enter the path of the image you want to edit.
4. Choose an operation from the menu.
5. Follow the instructions and save your edited image.

##  What I Learned

While building this project, I got hands-on practice with Python functions, user input, file handling, and image processing using Pillow.
